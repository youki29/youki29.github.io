3-1　恒常性と神経系

体内環境と恒常性

  • 生物体内の細胞を取り巻く環境を体内環境という。ヒトの多くの細胞は体液に浸されている
  • 体内環境を一定の範囲に保つ性質を恒常性（ホメオスタシス）という
  • 恒常性は、自律神経系と内分泌系によって情報が伝達されて調節されている

体液の3種類

体液 特徴
血液 血管内を流れる
組織液 血しょうが毛細血管からしみ出したもの。組織の細胞を取り巻く
リンパ液 組織液の一部がリンパ管に入ったもの。リンパ管は鎖骨下静脈と合流する

ヒトの神経系

神経細胞（ニューロン）などで構成される器官のまとまり。

  • 中枢神経系：脳と脊髄
  • 末梢神経系
    • 体性神経系：感覚神経・運動神経
    • 自律神経系：交感神経・副交感神経

脳の各部の役割

  • 脳は大脳・間脳・中脳・小脳・延髄などに分かれる
  • 意識や思考などの中枢：大脳。この機能だけが消失した状態を植物状態という
  • 生命維持の中枢部位：脳幹（間脳・中脳・延髄）

自律神経系

  • 自律神経系は、間脳の視床下部が総合的な中枢。意思とは無関係に働く
  • 交感神経：興奮状態で働きが優位。中枢神経系からの出どころは脊髄
  • 副交感神経：リラックス状態で働きが優位。出どころは中脳・延髄・脊髄の尾部
  • 神経（電気信号）により器官に直接作用するので、すばやく働く
器官 交感神経 副交感神経
瞳孔 拡大 縮小
汗腺（発汗） 促進 分布していない
立毛筋・体表の血管 収縮 分布していない

  • 交感神経と副交感神経は、同じ器官に分布していることが多い
  • 器官での働きは反対で、互いに拮抗的に作用する

心臓の拍動調節

  • 心臓はペースメーカー（洞房結節）により自発的に拍動する。場所は右心房と大静脈の境界付近
  • 自律神経系はペースメーカーに作用して拍動を調節する。拍動の中枢は延髄

3-2　恒常性と内分泌系

腺とホルモン

  • 腺：化学物質を分泌する細胞（腺細胞）の集まり
  • 外分泌腺：排出管を通して体外に化学物質を放出する（分泌物：汗・消化液）
  • 内分泌腺：血液中に化学物質を放出する（分泌物：ホルモン）
  • ホルモン：内分泌され、細胞間の情報伝達を担う物質。血液の循環で全身へ送られる
  • 特定の器官や組織の標的細胞にしか作用しない。ホルモンの調節を受ける器官を標的器官という
  • 標的細胞は、特定のホルモンと結合する受容体をもつ
  • ホルモンは微量で作用を示す
  • 自律神経系と比べると、効果が現れるまで時間はかかるが、作用には持続性が見られる

主な内分泌腺とホルモン

  • ホルモン分泌の総合的な中枢は間脳の視床下部
  • 脳の神経細胞がホルモンを分泌する現象を神経分泌、その細胞を神経分泌細胞という

例1：チロキシンが不足したとき

  1. 間脳の視床下部が甲状腺刺激ホルモン放出ホルモンを分泌
  2. 脳下垂体前葉が甲状腺刺激ホルモンを分泌
  3. 甲状腺からチロキシンの分泌量が増加（代謝が促進）
  4. チロキシンが増えると、視床下部と脳下垂体の分泌が抑えられる（負のフィードバック）

例2：血液中の物質濃度が上昇したとき

  1. 間脳の視床下部の神経分泌細胞がバソプレシンを生成
  2. 脳下垂体後葉からバソプレシンを分泌
  3. 腎臓の集合管で水の再吸収が促進 → 血液中の物質濃度が低下

血糖と肝臓の血管

  • 血糖＝血液中のグルコース。濃度調節にかかわる器官は肝臓や筋肉
  • 正常値（空腹時）：血液100mL中に約100mg（約0.1%）
  • グルコースが枝分かれして結合するとグリコーゲンになる
  • 高血糖時：肝細胞でグルコースからグリコーゲンを合成 → 血糖濃度低下
  • 低血糖時：肝細胞でグリコーゲンを分解 → 血糖濃度上昇
血管 血液の流れ
肝動脈 心臓から出た血液が肝臓へ流れる
肝静脈 心臓へ戻る血液が肝臓から流れる
肝門脈 小腸などの消化管の静脈が集合したもの。吸収したグルコースなどを含む血液が肝臓へ流れる

高血糖時の調節

  1. 中枢：間脳の視床下部が感知（すい臓のランゲルハンス島も感知）
  2. 副交感神経を通じて伝達
  3. すい臓のランゲルハンス島B細胞 → インスリンを分泌
  4. 働き：主に肝臓でグリコーゲンを合成、体の各細胞でグルコースの消費を促進

低血糖時の調節

  1. 中枢：間脳の視床下部が感知
  2. 交感神経を通じて伝達
  3. 副腎髄質 → アドレナリン、ランゲルハンス島A細胞 → グルカゴンを分泌
  4. 働き：主に肝臓でグリコーゲンを分解
  5. 極度の低血糖時：視床下部 → 放出ホルモン → 脳下垂体前葉 → 副腎皮質刺激ホルモン → 副腎皮質 → 糖質コルチコイド（タンパク質の糖化）

肝臓

  • 基本単位：肝小葉（約50万個の肝細胞からなる。肝臓全体で約50万個）
主な働き 内容
尿素の合成 タンパク質の分解で生じる有害なアンモニアを、害の少ない尿素に変える
解毒作用 有害な物質を無害にする
胆汁の合成 胆管を通って胆のうに蓄えられる。十二指腸へ分泌され、脂肪の消化を助ける

血糖濃度調節の流れ

血糖濃度が高いとき 血糖濃度が低いとき
伝える神経 副交感神経 交感神経
分泌するところ すい臓のランゲルハンス島B細胞 副腎髄質・ランゲルハンス島A細胞・副腎皮質

  • 結果は視床下部に戻って調節される（フィードバック）

糖尿病

  • 糖尿病：血糖濃度が高い状態が続く病気。合併症が引き起こされるほか、血糖濃度が一定以上になるとグルコースが尿中に排出される
  • Ⅰ型糖尿病：何らかの原因で、すい臓のランゲルハンス島B細胞が破壊 → インスリンの不足による（治療：インスリンの投与）
  • Ⅱ型糖尿病：主に生活習慣が関係することが多い → インスリンの分泌量の低下や、標的細胞の反応の低下による
  • グラフ：健常者は食後に血糖濃度が少し上がってすぐ戻り、インスリン濃度は大きく上がる。Ⅰ型糖尿病患者は血糖濃度が高いままで、インスリン濃度はほとんど上がらない

腎臓

  • 基本単位：ネフロン（腎単位）。腎臓1個に約100万個
  • 皮質側：腎小体（糸球体とボーマンのうからなる）／髄質側：細尿管（集合管につながり、腎うへ）
働き 内容
①ろ過 血液から原尿ができる過程。糸球体からボーマンのうへこし出される
②再吸収 原尿から必要な成分を血液に戻す過程。ろ過された物質の多くが細尿管や集合管から毛細血管へ再吸収される → 残りが尿
  • Q1：ろ過されない物質 → タンパク質・血球
  • Q2：すべて再吸収される物質 → グルコース
  • 体液の状態に応じて再吸収される物質：水（関与するホルモン：バソプレシン）、無機塩類（関与するホルモン：鉱質コルチコイド、Na⁺の再吸収）
  • Q3：原尿は1日約180L、尿は1日約1.44L
  • Q4：尿検査で正常なら、尿タンパク（−）、尿糖（−）、尿潜血（−）

3-5　血液の成分と血液凝固・体温の調節

血液の成分

ヒトの血液の総量は体重の約8%。

成分 名称 働き 特徴
液体成分（約55%） 血しょう 養分や老廃物などの運搬 90%は水。他にグルコース・二酸化炭素・タンパク質・ホルモンなど
細胞成分（約45%） 赤血球 酸素の運搬 赤い色素タンパク質ヘモグロビンをもつ。哺乳類では核をもたない
細胞成分 白血球 免疫に関与 核をもつ。さまざまな種類がある。血管外にも存在する
細胞成分 血小板 血液凝固に関与 核をもたない細胞片
  • すべての血球は、骨の内部の骨髄にある造血幹細胞から作られる

血液凝固

  1. 血小板が集まり、傷口をふさぐ
  2. カルシウムイオンや凝固因子などが働く（関与するホルモン：パラトルモン）
  3. 血ぺいの形成により傷口をふさぐ。血ぺいは繊維状タンパク質のフィブリンと血球が絡み合ったもの
  4. 血管の修復後、血ぺいを酵素で取り除く＝線溶（フィブリン溶解）
  • 採血した血液を放置すると、沈殿物として血ぺいができ、上澄みを血清という（血しょうからフィブリンの元が除かれた液体）
