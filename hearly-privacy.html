Hearly プライバシーポリシー

制定日：2026年10月25日

Hearly（以下「本アプリ」）は、利用者の情報を次のとおり取り扱います。

1. 学習の記録

回答した英文・正誤・学習時間・復習リスト・設定などの情報は、利用者の端末の中にだけ保存されます。開発者のサーバーに送信されることはありません。登録やログインもありません。アプリを削除すると、これらの情報も削除されます。

2. 英語の音声

英文の読み上げには、iPhone に内蔵された音声合成を使います。読み上げのために文章を外部へ送ることはありません。

3. ニュースの取得

「ニュース」タブに表示するニュースのファイルを、開発者のサイト（youki29.github.io）から取得します。このとき利用者の情報は送信しません（一般的な Web ページの閲覧と同様に、IP アドレスなどの通信情報はサイトの配信事業者である GitHub に記録される場合があります）。

4. 通知

学習のリマインダー通知は、利用者が設定で有効にした場合にのみ、端末の中で予約されます。通知の内容が外部に送信されることはありません。

5. 広告

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。AdMob は、広告の配信・効果測定・不正防止のために、端末の識別子（広告 ID）、おおよその位置情報（IP アドレスから推定）、アプリの利用状況などを収集することがあります。

  • iPhone では、利用者が「トラッキングを許可」した場合にのみ、広告 ID が利用者に合わせた広告に使われます。許可しない場合も本アプリはすべての機能を使えます。
  • 「Hearly プレミアム」または「広告削除」をご利用中は、広告は表示されません。

Google による情報の取り扱いについては、Google の広告に関するポリシーをご覧ください。

6. アプリ内課金

購入・自動更新・解約の手続きは Apple の App Store で行われます。支払い情報を本アプリや開発者が受け取ることはありません。月額・年額プランは、iPhone の「設定」→ Apple アカウント →「サブスクリプション」からいつでも解約できます。

7. 第三者への提供

上記の広告サービスを除き、利用者の情報を第三者に提供することはありません。

8. お子さまの利用について

13歳未満の方は、保護者の方の同意のうえでご利用ください。

9. 本ポリシーの変更

本ポリシーを変更する場合は、このページでお知らせします。
